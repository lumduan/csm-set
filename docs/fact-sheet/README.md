## 1. กลยุทธ์นี้คืออะไร และดียังไง

**แนวคิดหลัก (Momentum):** "หุ้นที่กำลังขึ้น มักขึ้นต่อในระยะสั้น" กลยุทธ์จัดอันดับหุ้นไทยทั้งตลาดตามผลตอบแทนย้อนหลัง 12 เดือน (เว้นเดือนล่าสุด 1 เดือน) แล้ว**ซื้อกลุ่มที่แข็งแกร่งที่สุด 20% บนสุด** ถือไว้ และทบทวนพอร์ตใหม่ทุกสิ้นเดือน

**จุดเด่น**

- **เอาชนะ SET ได้จริงในระยะยาว** — โตเฉลี่ย 12.5%/ปี เทียบกับ SET ที่ 7.3%/ปี (ส่วนเกิน ~5%/ปี ตลอด 17 ปี)
- **เป็นระบบ ไร้อารมณ์** — ใช้กฎตายตัว วัดผลซ้ำได้ ไม่ได้เดาหรือใช้ความรู้สึก
- **มีกลไกควบคุมความเสี่ยง** — กรองสภาพคล่อง, จำกัดน้ำหนักรายตัว/รายกลุ่ม, มีระบบตัดขาดทุน (Circuit Breaker)
- **ทนต่อค่าธรรมเนียม** — ผลแทบไม่เปลี่ยนเมื่อต้นทุนเพิ่มจาก 15 เป็น 25 bps

**ลักษณะพอร์ต**

| รายการ | ค่า |
|---|---|
| ตลาด | หุ้นไทย SET |
| จำนวนหุ้นเลือกได้ | ~496 ตัว/รอบ |
| ปรับพอร์ต | รายเดือน |
| สัญญาณ | Residual Momentum |
| ถ่วงน้ำหนัก | เท่ากัน / ตามความผันผวน |
| ช่วงทดสอบ | 2009–2026 |
| ทุนเริ่มต้น (อ้างอิง) | 1 ล้านบาท |

> **หมายเหตุ:** นี่คือ "กลยุทธ์เชิงปริมาณ (Quant)" ไม่ใช่กองทุนจริง ตัวเลขทั้งหมดมาจากการจำลองย้อนหลัง (Backtest)

## 2. ผลตอบแทนและความเสี่ยง (เทียบ SET)

ผลจาก Backtest ช่วง ม.ค. 2009 – มี.ค. 2026 หักต้นทุนซื้อขาย 15 bps แล้ว · Benchmark = SET Total Return Index (รวมเงินปันผล)

| ตัวชี้วัด | ค่า |
|---|---|
| ผลตอบแทนทบต้น/ปี (CAGR) | **12.5%** (SET: 7.3%) |
| Sharpe Ratio | 0.66 |
| Sortino Ratio | 0.85 |
| Calmar Ratio | 0.40 |
| ขาดทุนสูงสุด (Max Drawdown) | **−31%** |
| ความผันผวน/ปี | 17% |
| สัดส่วนเดือนที่กำไร | 43.9% |
| อัตราหมุนพอร์ต/ปี | ~250% |

**อ่านง่าย ๆ:** ถ้าลงทุน 1 ล้านบาทแบบทบต้นที่ 12.5%/ปี เทียบกับ SET ที่ 7.3%/ปี ส่วนต่าง ~5%/ปี เมื่อทบต้น 17 ปีจะกลายเป็นเงินที่ต่างกันหลายเท่าตัว — แต่ต้องแลกมากับการ "ทนเห็นพอร์ตติดลบได้ถึง −31%" ในบางช่วง

## 4. ข้อมูลน่าเชื่อถือแค่ไหน

**โดยรวม: กระบวนการวิจัยอยู่ในระดับมืออาชีพ** มีการป้องกันข้อผิดพลาดที่นักลงทุนทั่วไปมักมองข้าม แต่ก็มีข้อควรระวังสำคัญที่ต้องเข้าใจ

**จุดที่น่าเชื่อถือ**

- **ใช้ข้อมูล Total Return** (ปรับปันผล + แตกพาร์แล้ว) สะท้อนผลตอบแทนจริงของผู้ถือหุ้น — หุ้น 696 ตัว ครอบคลุมเกือบทั้ง SET
- **กัน Look-ahead Bias** — ใช้ "ภาพ universe ณ วันนั้นจริง ๆ" (Dated Snapshots) ไม่แอบใช้ข้อมูลอนาคต
- **มีการทดสอบนอกตัวอย่าง (Walk-Forward OOS)** และ**ไม่พบสัญญาณ Overfitting** (IS/OOS Sharpe = 1.87 ต่ำกว่าเกณฑ์เตือน 2.0)
- **ทดสอบความทนทานหลายมิติ** — ค่าธรรมเนียม, การกระจุกตัว, สภาพคล่อง, Monte Carlo

**ข้อควรระวัง**

- **สัญญาณค่อนข้างอ่อน** — พลังพยากรณ์ (Mean IC ≈ 0.027, Rank ICIR ≈ 0.32) ผ่านเกณฑ์แบบ "เฉียด ๆ" และ Composite เหลือสัญญาณเดียว (Residual Momentum)
- **OOS อ่อนกว่า In-sample ชัดเจน** — Sharpe ตกจาก 0.66 เหลือเฉลี่ย 0.35 ในการทดสอบนอกตัวอย่าง (บาง fold ติดลบ)
- **Notebook 04 (Portfolio Optimization) ใช้ข้อมูลสังเคราะห์ (Synthetic)** — ตัวเลขสวย ๆ อย่าง CAGR 36% / Sharpe 2.69 **ไม่ใช่ผลจริง** เป็นเพียงการทดสอบว่ากลไกพอร์ตทำงานถูกต้อง
- **Phase 1 มี 2 เกณฑ์ที่ขึ้น FAIL** (path ดัชนี SET และหุ้น 2 ตัวไม่มีข้อมูล) — เป็นเรื่องเชิงเทคนิคเล็กน้อย แต่ควรเคลียร์ก่อนใช้จริง

> **สรุปเรื่องตัวเลข:** ให้ยึด **ผลจาก Notebook 03 (CAGR 12.5% / Sharpe 0.66 / DD −31%)** เป็นภาพผลตอบแทน "จริง" ที่ใกล้เคียงที่สุด — ส่วนตัวเลขใน Notebook 04 ให้มองเป็น "การทดสอบระบบ" ไม่ใช่ผลตอบแทนที่คาดหวัง

## 5. ระดับความเสี่ยง

| ความเสี่ยง | ระดับ | คำอธิบาย |
|---|---|---|
| ขาดทุนรุนแรง (Drawdown) | สูง | เคยติดลบ −31% และบางครั้งใช้เวลานานถึง ~38 เดือนกว่าจะกลับทุน |
| Momentum Crash | สูง | ช่วงตลาดกลับตัว/หมุนกลุ่ม กลยุทธ์อาจแพ้ SET แรง (เช่น 2022 −22.6%) |
| ต้นทุนซื้อขาย/Slippage | ปานกลาง | หมุนพอร์ตสูง ~250%/ปี มีค่าซื้อขายซ่อนเร้น โดยเฉพาะหุ้นสภาพคล่องต่ำ |
| ข้อจำกัดด้านขนาดเงินทุน | ปานกลาง | ออกแบบสำหรับเงินระดับรายย่อย (~1 ล้านบาท) เงินก้อนใหญ่จะกระทบราคา |
| ความผันผวน | ปานกลาง | 17%/ปี สูงกว่าการถือกองดัชนีเฉย ๆ เล็กน้อย |
| Model/Overfitting | ปานกลาง | ผล OOS อ่อนกว่า IS แม้ยังไม่ถึงขั้นเตือน — ต้องเฝ้าติดตามต่อเนื่อง |

**เหมาะกับนักลงทุนที่** รับความผันผวนได้สูง เข้าใจว่าจะมีหลายปีที่แพ้ตลาด และลงทุนได้**ยาวอย่างน้อย 5–7 ปี** เพื่อให้ความได้เปรียบของ Momentum แสดงผล

## 6. วิธีอ่าน Notebooks 01–04 สำหรับนักลงทุน

เอกสาร 4 ไฟล์คือ "ขั้นตอนการสร้างและพิสูจน์กลยุทธ์" เรียงจากข้อมูลดิบ → สัญญาณ → ทดสอบ → จัดพอร์ต ไม่จำเป็นต้องอ่านโค้ด ให้โฟกัสที่ **หัวข้อภาษาไทย + ตารางสรุป + กล่อง Sign-off (PASS/FAIL) ท้ายแต่ละไฟล์**

- **01 — ตรวจคุณภาพข้อมูล (Data Quality):** ดูว่า "วัตถุดิบ" ดีพอไหม — ข้อมูลครบ ไม่มีรู, สภาพคล่องผ่านเกณฑ์, กันอคติการอยู่รอด (Survivorship). อ่านแค่**ตาราง Sign-off ส่วนที่ 7** ก็พอ
- **02 — วิจัยสัญญาณ (Signal Research):** ดูว่า "สูตรเลือกหุ้น" มีพลังพยากรณ์จริงไหม — ตาราง **ICIR** (ยิ่งสูงยิ่งดี, เกณฑ์ผ่าน >0.3) และ **Q5−Q1 Spread**
- **03 — Backtest (สำคัญที่สุด):** "ผลตอบแทนเสมือนจริง" — **ตาราง Performance Summary** (CAGR/Sharpe/Max DD), **กราฟ Equity Curve เทียบ SET**, **ตารางผลรายปี** และ **Walk-Forward OOS**. ตัวเลขในไฟล์นี้คือสิ่งที่ควรเชื่อถือที่สุด
- **04 — จัดพอร์ต/ควบคุมความเสี่ยง (Optimization):** ทดสอบ "กลไกเสริม" เช่น คุมความผันผวน, ตัดขาดทุนอัตโนมัติ, Monte Carlo. **ข้อควรระวัง: ไฟล์นี้ใช้ข้อมูลสังเคราะห์** — อย่านำตัวเลขผลตอบแทนไปคาดหวัง

> **ทางลัด 60 วินาที:** เปิด Notebook 03 → ดูตาราง Performance + กราฟ Equity Curve เทียบ SET → ดูตารางผลรายปีว่าปีไหนแพ้แรง. เท่านี้ก็เห็นภาพ "ดี/เสี่ยง/คุ้มไหม" ครบแล้ว
